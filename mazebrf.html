Tactile Maze Maker

Makes finger-tracing mazes as BRF files for a braille embosser. The walls are single lines of dots, and the student traces the open space between them.

Spacing values are in mm, measured center to center. They only affect the preview and how the path width gets rounded. The defaults are standard US braille spacing.

Embossing with BrailleBlaster

  
    
    
  1. Click Download .brf.
    2. 
    
  2. In BrailleBlaster, open the file with File › Open. A BRF opens in Braille Preview exactly as it was laid out and can't be edited there.
    3. 
    
  3. Choose File › Emboss (Ctrl+E), pick your embosser and set Interpoint to No.
    4. 
  

  
    
    
  • Cells per line and lines per page here need to match the embosser's page settings. If they're larger, lines will wrap and break the maze.
    • 
    
  • Emboss one test page first. If the paths feel too narrow or too wide, change the path width and try again.
